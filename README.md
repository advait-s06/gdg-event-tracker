# It's your turn to try and create an app in React!
## Your final test will be to create a page based on the wireframe you made earlier.

### Parts that need to be done:
1) Header with event name
2) Area for date, time, location
3) A sign up button\*
4) Any indication of confirmation that the user has signed up\*

\*These two are a bit challenging but give it a try!

### Getting started
1) Clone this repo on your local machine
2) Make sure that Vite and Node.js are downloaded!
3) Create a new React app using Vite
4) Get to programming!
